# 时光留存 · QQ 空间备份

这是独立 Windows 桌面程序，不需要向 Chrome/Edge 安装扩展。

## 快速开始

1. 双击 `TimeCapsule.exe`。支持 Windows x64，自带 .NET 运行时。
2. 点击左侧“打开扫码登录窗口”，在 QQ 官方网页手动扫码。
3. 进入自己的空间主页后，点击登录窗口右下方“已登录，连接此账号”。
4. 目标 QQ 号留空即可备份当前账号。填写其他 QQ 号时，仅能导出当前账号有权限访问的内容。
5. 选择保存位置。程序会在下面按目标 QQ 号建子文件夹，建议保留默认“稳妥 · 3 秒”。
6. 点击“开始备份 / 继续补采”。完成或停止后，点击“打开离线档案”。

需要快速验证时，展开“快速验证一条说说”，粘贴 `https://user.qzone.qq.com/QQ号/mood/说说ID` 或说说 ID，再开始备份。多条可用空格分隔。结果写入目标账号下面单独的“验证-...”子目录，明确标注“不是全量备份”。清空该字段即可做完整导出。

## 本版实现

- 逐页采集本人说说列表，按说说 ID 去重；不依赖只有互动才出现的历史互动流。
- 逐条请求正文详情，保存长正文和转发正文。接口若仍标记截断，会进入核对报告。
- 独立分页请求评论，不按作者过滤，因此保留本人评论及接口返回的自回复。
- 合并列表、详情与评论接口返回的评论，保留 `list_3` / `replys` / `replies` 回复结构。
- 评论/回复的已知计数有缺口时报告，不宣称能恢复接口未返回的内容。
- 保存图片、更多图片、评论配图，以及能够直接取得的 MP4 / 部分音频媒体。
- 保存日期时间、转发正文、说说分享卡片中的文字和链接。外链文章本身不抓取。
- 可选读取点赞者；浏览量仅显示接口已返回的字段。
- 可选留言板（实验性，原始字段保留在 JSON 中）。
- 请求重试、随机请求间隔、暂停、停止保存、重新补采和全量详情复核。
- 离线 HTML 时间线，正文/评论搜索、年份筛选；JSON、Markdown 和核对报告。

## 尚不支持

独立分享页、日志、私密日志、独立相册、QQ 聊天记录、已删除内容恢复、超出登录账号权限的内容。不承诺全部楼中楼回复：某些接口只返回部分回复，缺口会记录。视频链接失效或没有直接媒体地址时仅保留记录。

## 导出文件

| 文件 | 用途 |
|---|---|
| `index.html` | 双击在浏览器离线阅读 |
| `archive.json` | 完整结构化备份、原始字段和续传状态 |
| `archive.json.bak` | 上次运行开始前的备份快照 |
| `report.json` | 本轮数量、状态和待核对项 |
| `说说.md` | 便于检索的文本与评论 |
| `media/` | 已下载的图片及媒体 |
| `.lock` | 防止两个窗口同时写同一备份，文件存在本身不代表仍被锁定 |
| `run.log` | 任务进度与错误信息，不记录登录 Cookie 或令牌 |

保存时使用临时文件替换。停止会输出当前已取得的内容；重新开始会从首页核对列表，复用完成的详情与媒体，避免动态列表偏移变化造成断点漏采。勾选“重新核对所有全文与评论”可重新读取完成的详情。历史档案保留旧记录，不自动删除网络上已删除的内容。

## 如何核对你遇到的两类缺失

1. 找一条较长的说说，在网页中确认它的最后一段，然后在离线档案搜索同一句话。
2. 找一条自己给自己留言/回复的说说，在离线档案展开评论，对照评论正文、时间和楼中楼。
3. 查看“完整性核对”，不要只看说说总条数。条数相同不证明正文/评论都齐全。
4. 如果接口提示繁忙，停止后等待，再选更慢间隔补采。如果登录失效，重新扫码。

## 登录和本地数据

登录浏览器采用本工具自己的 WebView2 用户目录，不读取你日常浏览器的 Cookie。QQ 密码由 QQ 官方网页处理；程序不保存明文密码，也不在备份中保存 Cookie / g_tk / qzonetoken。WebView2 会在当前 Windows 用户的 `%LOCALAPPDATA%\TimeCapsule\Browser` 保留会话。点击“退出登录 / 清除会话”可清除。

本工具不上传备份、不带遥测或远程统计。离线网页不自动加载远程图片；只有点击“原链接”才会打开联网页面。

需要 WebView2 Runtime。本机检查已找到可用 Runtime；在其他电脑若缺失，请从 Microsoft 官方页面安装： https://developer.microsoft.com/microsoft-edge/webview2/
