# 时光留存 1.2.1 · 我的离线空间

## 接着上次备份

默认“智能续传 / 核对变化”：核对列表摘要，复用已完成的正文、评论和本地文件，只采集新增、检测到变化或尚未完成的记录。保存上次的账号、目录、范围及下载选项，下次启动自动恢复。不会保存 QQ 密码或登录令牌到这些设置中。

列表核对比较正文预览、可见修改字段、图片/视频信息、评论数量和返回的评论样本；即使条数没变，正文预览变化也会触发重新核对。已经完成且没有检测到变化的记录，不再逐条重写整个 JSON。

“只补已有档案”跳过网络列表，只补已有记录的缺失部分；不检查新增说说。档案页“补采当前档案”会选择当前打开的 JSON 所在目录，再点击开始即可。原始 JSON 旁的 media 文件夹应一起保留。

列表接口不一定能体现旧评论的所有文字修改；需要严格复查全部历史正文/评论时，勾选“深度复核全部正文与评论”。本地备份保留历史记录，不自动删除网上已消失的内容。

## 去重

说说按 ID 合并，评论与回复按各自 ID 合并；旧 JSON 中重复的说说会在读入或续传时合并，优先保留较长正文和不同的评论。相同 ID 的实质性正文差异保留候选版本。不同 ID 的同文说说保留，避免误删重复发布的内容。

新下载的图片、视频、头像和表情按实际文件内容的 SHA-256 命名，相同字节只存一份；多个来源链接可引用同一文件。导入/导出也使用文件内容去重。旧备份的遗留文件不会被批量删除，合并导出可获得重新整理的目录。

## emoji、头像与昵称

保留 Unicode emoji；解析 QQ 的 [em]e数字[/em] 表情并下载到本地。解析 @{uin:...,nick:...} 提及，显示 @昵称；支持多种作者字段以及独立的回复对象昵称。昵称缺失时尝试使用档案中同一账号的已知昵称。

头像和 QQ 表情独立勾选，不受“下载图片”开关影响。头像保存的是下载时的当前头像，不能还原发帖年代的旧头像。某个表情下载失败时显示可辨识的文字占位，并记录待核对项。

## 部分备份与速度

可选智能续传、最近 N 条、日期范围、只补已有档案，也可通过说说链接/ID 指定记录。最近 N 条达到目标后停止列表翻页；日期范围只补全范围内的详情，为避免漏掉顺序异常的记录，仍会核对列表。

图片、音视频、评论、头像、QQ 表情分别选择；未勾选采集评论不会删除已经保存的评论。附件下载可选 1 / 4 / 8 路并发。接口请求间隔可选 0.8 / 1.8 / 3 / 5 秒，失败会退避重试。默认 1.8 秒、4 路附件下载。并发作用于附件，正文/评论接口仍按顺序访问。实际速度受账号接口响应和网络影响。

## 个人空间阅读页

顶部封面与头像、横向导航、侧栏信息、说说与分层评论。支持晴空蓝、旧信纸、夜间三种主题；可调整字号、行距、阅读宽度、黑体/宋体、九宫格/大图/纯文字、评论显示。设置保存在当前浏览器。可临时选择本地封面，不上传，重新打开页面需重新选择。

时间线图片和 Gallery 均支持大图查看；搜索与日期过滤联动画廊；“偶遇一条回忆”随机定位当前显示的说说。

TXT / HTML / JSON 导出、日期筛选、档案导入合并继续保留。给 AI 分析优先使用 TXT 和阅读说明；图片分析需要另外提供对应图片。

## 使用新版

1. 等旧窗口结束，或点击“停止并保存”，再关闭旧窗口。
2. 打开 TimeCapsule.exe，选择原来的保存位置和目标账号，使用“智能续传 / 核对变化”。
3. 也可在档案页打开已有 archive.json，再点击“补采当前档案”。
4. 需要头像和 QQ 表情时保留对应勾选，开始后会复用已有媒体。

## 验证与边界

最终本地回归 76 项通过。此前另有 3 项真实 CDN 检查通过：QQ 表情和空间主人头像能下载，文件名与文件内容摘要一致。共下载 12 个头像、16 个 QQ 表情测试资源，无失败。真实两条旧备份的 6062 字正文、评论样例的 15 条评论和 2 条回复保持不丢失。
