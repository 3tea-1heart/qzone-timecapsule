# 1.1.0：档案整理与可读导出

新增“档案整理与导出”页，打开本工具 archive.json 后即可使用，无需重新登录。

- 按关键词搜索正文、作者、转发、评论与回复；多个关键词按同时匹配处理。
- 自选起止日期（包含两端整天）、内容类型，或 Ctrl / Shift 多选说说。
- 导入同一账号的多个 JSON 档案，另存合并结果。相同说说 ID 合并，优先保留更长正文、合并评论和附件；有实质差异的正文保留候选版本。不同 ID 的相似文字不自动删除，避免误删重复发布的说说。
- 相同媒体按文件内容去重。导入时请保留原 JSON 旁边的 media 文件夹。
- 可勾选正文、评论、图片、音视频、转发分享、点赞者；导出 TXT、HTML、JSON 中的一种或多种。
- TXT 使用 UTF-8，中文直接可读，每 100 条分卷，整条说说不被切开；保留稳定 ID、作者、日期、正文、转发、评论回复层级、附件位置和核对状态。
- HTML 包含时间线、日期/关键词筛选，以及独立 Gallery。画廊支持本地图像大图查看、音视频播放和返回对应说说。
- JSON 使用缩进和可读中文，可再次导入本工具。按需导出的 JSON 只包含勾选字段，不等同完整采集档案。

## 给 AI 分析

优先使用导出的“说说.txt”或“说说-001.txt”等分卷，并附带“阅读说明.txt”。需要图片分析时还需提供对应图片文件；TXT 中的本地路径不会让 AI 自动读取图片。更长的单条正文不会强行截断；若平台上传限制较小，可缩小日期范围后分别导出。

建议分析要求：区分原作者、转发作者和评论者；引用说说 ID 与日期；不要把未选择导出、未完成采集当成没有发生；候选正文版本属于同一条记录，避免重复计数。

## 操作顺序

1. 启动 TimeCapsule.exe，切换“02 档案整理与导出”。
2. 打开旧备份 archive.json；需要合并多个备份时点击“导入、合并与去重”。
3. 输入关键词、选择日期和类型，点击记录阅读全文。
4. 选择需要的内容及格式，点击“选择位置并导出”。程序自动新建目录，不覆盖原备份。
5. “生成离线 Gallery”会按当前筛选创建独立 HTML 阅读目录，并在浏览器打开。
