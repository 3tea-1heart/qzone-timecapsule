# GitHub 同步与发布

仓库：https://github.com/3tea-1heart/qzone-timecapsule ，公开。

日常更新：修改源码和文档，运行测试，检查提交内容，提交并推送 main。AGENTS.md 已记录后续更新同步 GitHub 的要求；尚未提交、推送的本地修改不会自动同步。

发布新版本：

1. 更新项目文件 Version，并编写 `docs/更新说明-X.Y.Z.md`。
2. 使用新目录运行测试，执行 `build.ps1`，检查程序。
3. 提交并推送 main，再创建并推送匹配的 `vX.Y.Z` 标签。
4. 等待 Actions 完成，检查 Releases 中 ZIP 和 SHA-256。

不要重复使用已发布版本的标签。修复问题后根据情况重跑或发新版本。

`exports/`、`artifacts/`、`release/`、`.tools/` 和登录数据均被忽略。只提交源码、合成测试、文档及工作流。发行包通过 Releases 提供，不进入 Git 历史。

登录使用 GitHub 官方工具，不在项目中保存令牌。工作流通过临时令牌发布，普通构建仅有只读权限。

参考：[GitHub .NET 构建文档](https://docs.github.com/en/actions/tutorials/build-and-test-code/net)、[GitHub CLI 发布命令](https://cli.github.com/manual/gh_release_create)。
